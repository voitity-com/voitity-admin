# Face Detector model

`blaze-face-short-range-float16.tflite` comes from the official MediaPipe model bucket:

`https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/latest/blaze_face_short_range.tflite`

It is used only for the client-side avatar precheck. The Laravel API and AWS Rekognition remain authoritative.
